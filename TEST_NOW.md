# 🚀 TEST NOW - Quick Start

**3-Minute Test Guide**

---

## ⚡ FASTEST WAY TO TEST

### **1. Test Voice Onboarding** (2 min)

**In browser console:**
```javascript
localStorage.removeItem('echo:seen-welcome');
```

**Then:**
1. Log out
2. Log back in
3. Welcome modal appears! 🎉

**Try:**
- Click "Local AI Experience" (download path)
- OR click "Skip for Now" (regular path)

---

### **2. Test Voice Button** (30 sec)

1. Go to Settings → Voice tab
2. Click "Test Voice" button
3. Should hear: "Hello! I'm Echo..."
4. Button should be **purple** (if API key set)

---

### **3. Test Voice Commands** (30 sec)

**Click microphone button and say:**
- "Add weather widget"
- "Show me my tasks"
- "What's the weather"

---

## ✅ SUCCESS CRITERIA

**If these work, you're good to go:**
- ✅ Welcome modal appears
- ✅ Test Voice plays audio
- ✅ Voice commands execute
- ✅ Widgets persist after logout

---

## 🐛 IF SOMETHING BREAKS

**Quick Fixes:**
1. Hard refresh: `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac)
2. Clear cache: DevTools → Application → Clear storage
3. Check console for errors
4. Report issue

---
