## 🚀 HOW TO USE

### **Stocks Widget:**
```
1. Click "Edit" on dashboard
2. Click "+" button
3. Select "Stocks"
4. Done! Auto-refreshes every minute
```

### **News Widget:**
```
1. Click "Edit" on dashboard
2. Click "+" button
3. Select "News"
4. Click "Change Source" to customize
```

### **Forgot Password:**
```
1. Click "Forgot your password?" on login
2. Enter email
3. Check inbox
4. Click reset link
5. Set new password
```
