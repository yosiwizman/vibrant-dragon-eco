# 🚀 QUICK START GUIDE
**Echo AI - New Features**

---

## 🎯 5-MINUTE SETUP

### **Step 1: Login**
1. Go to Echo AI
2. Login with your account
3. You're ready!

---

### **Step 2: Add Widgets**
1. Click **"Edit"** button on dashboard
2. Click **"+"** to add widgets
3. Select **"Stocks"** or **"News"**
4. Click **"Done"**

**Your widgets are now saved forever!** ✅

---

### **Step 3: Configure Voice**
1. Go to **Settings → Voice**
2. Select your preferred voice
3. Click **"Test Voice"**
4. Hear your AI assistant!

---

### **Step 4: Customize**
- **Move widgets:** Drag them around
- **Resize widgets:** Drag corners
- **Remove widgets:** Click X in edit mode
- **Change news source:** Click settings icon

---

## 🐛 TROUBLESHOOTING

### **Widgets Not Saving?**
- Make sure you're logged in
- Check internet connection
- Try logout and login

### **Voice Not Working?**
- Check OpenAI API key in settings
- Try different browser
- Check console for errors

### **Stocks Not Updating?**
- Click manual refresh
- Wait for next auto-update (1 min)
- Check internet connection

### **News Not Loading?**
- Try different source
- Some sites block embedding
- Check internet connection
