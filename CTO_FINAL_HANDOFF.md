## ⚠️ KNOWN LIMITATIONS

### **Technical:**
1. **Browser Support** - WebGPU required for local AI (Chrome, Edge, Safari)
2. **Model Size** - 1.5-3GB download (one-time)
3. **Voice Quality** - Browser TTS varies by device
4. **Offline Limits** - No real-time data without internet

### **Business:**
1. **API Costs** - Users need OpenAI key for cloud features
2. **Storage** - Local AI requires device storage
3. **Competition** - ChatGPT, Notion AI, etc.
4. **Market Education** - Voice-first is new concept

### **Mitigations:**
- Clear communication about requirements
- Graceful fallbacks for unsupported browsers
- Free local AI option reduces friction
- Excellent onboarding reduces churn
